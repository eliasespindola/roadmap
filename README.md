# Roadmap Backend · Java + Go · 2026

Aplicação web em português com o caminho de carreira **Junior → Pleno → Senior → Staff** para backend, focado em **Java 25 LTS** e **Go 1.26**. Inclui tópicos, recursos curados (essencial / complementar / histórico) e fichas de desafio por complexidade. Os desafios são enunciados para você implementar no seu ambiente — a app não executa código.

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço que o Vite imprimir (em geral `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## O que tem aqui

- **Mapa mental:** visão em árvore (base, algoritmos, banco, Java/Go, produção, Staff) + percurso em fases
- **Colunas:** Junior → Staff, agora com fundamentos (GitHub, Linux, HTTP, SQL) e algoritmos
- **Desafios independentes:** cada um é um repo novo (domínio próprio)
- **IA e MCP:** trilha para leigos (LLM, agente, protocolo, skills)
- **Biblioteca:** livros e cursos que o mercado usa em 2026 + catálogo completo

Stack da interface: Vite, React, TypeScript, Tailwind CSS. Conteúdo versionado em `src/data/`.
